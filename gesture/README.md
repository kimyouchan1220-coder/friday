# 프라이데이 손짓 제어 (Windows)

웹캠으로 손을 인식해서 마우스와 단축키를 대신 조작하는 프로그램입니다.
영상은 컴퓨터 안에서만 처리하고 저장·전송하지 않습니다. Friday 웹앱과는 별개로 실행하며,
웹캠은 한 프로그램만 쓸 수 있으므로 Friday의 "손동작"과 동시에 켜지 마세요.

## 처음 한 번
1. Python 3.12를 설치합니다(https://www.python.org/downloads/). 설치 첫 화면에서 **Add python.exe to PATH**를 체크합니다.
2. 이 폴더의 `start_gesture.bat`를 더블클릭합니다. 처음에는 손 인식 라이브러리(mediapipe)와 모델(약 8MB)을 내려받습니다.

## 손동작
| 손 모양 | 동작 |
|---|---|
| 검지만 세우기 | 커서 이동 (손 전체를 움직이면 커서가 따라감) |
| 엄지+검지 집었다 떼기 | 왼쪽 클릭 (빠르게 두 번 = 더블클릭) |
| 엄지+검지 집은 채 이동 | 드래그 (창 옮기기, 파일 끌기) |
| 검지+중지 V, 위아래로 | 스크롤 |
| V 상태에서 엄지+중지 붙이기 | 오른쪽 클릭 |
| 손바닥 펴고 오른쪽/왼쪽으로 치우기 | 단축키 (기본: 크롬 탭 오른쪽/왼쪽) |
| 주먹 1초 유지 | 일시정지 / 재개 (삑 소리) |

- 미리보기 창의 사각형이 화면 전체에 대응합니다. 사각형 안에서 손을 움직이면 됩니다.
- 커서는 검지 뿌리 관절을 따라가므로 집는 동안 덜 흔들립니다. 집은 직후 0.25초는 커서를 고정해 클릭이 엉뚱한 곳에 눌리지 않게 합니다.
- 쓰지 않을 때는 주먹 1초로 일시정지하세요. 손이 화면 밖으로 나가면 누르고 있던 버튼은 자동으로 놓습니다.
- 미리보기 창에서 `p` 일시정지, `q` 종료.

## 손바닥 손짓 모드 (`start_gesture.bat --mode 이름`)
| 모드 | 오른쪽 손짓 | 왼쪽 손짓 |
|---|---|---|
| tab (기본) | Ctrl+Tab (오른쪽 탭) | Ctrl+Shift+Tab (왼쪽 탭) |
| window | Alt+Tab | Alt+Shift+Tab |
| snap | Win+→ (현재 창을 오른쪽 절반으로) | Win+← |
| desktop | Ctrl+Win+→ (다음 가상 데스크톱) | Ctrl+Win+← |
| slide | → (다음 슬라이드) | ← |
| media | 다음 곡 | 이전 곡 |

기타 옵션: `--no-mouse` (마우스 조작 끄기), `--speed 1.5` (작은 움직임으로 화면 끝까지), `--camera 1` (다른 카메라), `--no-preview`, `--sens 0.15` (손바닥 손짓 더 민감하게, 기본 0.2).

## 한계
- 조명이 어둡거나 손이 카메라에 너무 가깝거나 멀면 인식이 흔들립니다. 손바닥이 화면 높이의 1/4 정도로 보이는 거리가 적당합니다.
- 실제 마우스보다 정밀하지 않습니다. 작은 버튼, 글자 선택 같은 세밀한 작업은 어렵습니다.
- 관리자 권한으로 실행 중인 프로그램(작업 관리자 등)에는 입력이 들어가지 않습니다(Windows 보안 정책).
