# 프라이데이 손짓 제어 (Windows)

웹캠으로 손을 인식해서, 손바닥을 편 채 오른쪽/왼쪽으로 치우면 단축키를 대신 누르는 프로그램입니다.
영상은 컴퓨터 안에서만 처리하고 저장·전송하지 않습니다. Friday 웹앱과는 별개로 실행합니다.

## 처음 한 번
1. Python 3.12를 설치합니다(https://www.python.org/downloads/). 설치 첫 화면에서 **Add python.exe to PATH**를 체크합니다.
2. 이 폴더의 `start_gesture.bat`를 더블클릭합니다. 처음에는 손 인식 라이브러리(mediapipe)와 모델(약 8MB)을 내려받습니다.

## 사용
- 실행 후 **넘기고 싶은 창(예: 크롬)을 한 번 클릭**해 두세요. 키 입력은 맨 앞 창에 들어갑니다.
- 손바닥을 펴고 화면 앞에서 오른쪽 또는 왼쪽으로 빠르게 치웁니다(0.5초 안에 화면 폭의 20% 이상).
- 손을 되돌리는 동작은 1.6초 동안 무시합니다. 주먹이나 느린 움직임도 무시합니다.
- 미리보기 창에서 `p` 일시정지, `q` 종료.

## 모드 (`start_gesture.bat --mode 이름`)
| 모드 | 오른쪽 손짓 | 왼쪽 손짓 |
|---|---|---|
| tab (기본) | Ctrl+Tab (오른쪽 탭) | Ctrl+Shift+Tab (왼쪽 탭) |
| window | Alt+Tab | Alt+Shift+Tab |
| snap | Win+→ (현재 창을 오른쪽 절반으로) | Win+← |
| desktop | Ctrl+Win+→ (다음 가상 데스크톱) | Ctrl+Win+← |
| slide | → (다음 슬라이드) | ← |

기타 옵션: `--camera 1` (다른 카메라), `--no-preview` (미리보기 없이), `--sens 0.15` (더 민감하게, 기본 0.2).

## 한계
- 조명이 어둡거나 손이 화면 밖으로 너무 빨리 나가면 인식이 빠질 수 있습니다.
- 관리자 권한으로 실행 중인 프로그램(예: 작업 관리자)에는 키 입력이 들어가지 않습니다(Windows 보안 정책).
